帮我看下这段 LangGraph 的流式输出，为什么前端只收到一次完整结果？

大概率是 streamEvents 的版本参数没对上。LangGraph 在 v1 协议下会把同一节点的增量合并后再抛出，所以 for await 里只拿到了一次完整结果。按下面三点排查：

  1. 调用时显式传入 version: "v2"；
  2. 只处理 on_chat_model_stream 事件，忽略节点级事件；
  3. 每个 chunk 只追加 chunk.content，不要整体替换消息。
agent.ts 
for await (const evt of graph.streamEvents(input, { version: "v2" })) {
  if (evt.event !== "on_chat_model_stream") continue

  const chunk = evt.data.chunk
  if (chunk.content) onToken(chunk.content as string)
}

另外在 Electron 里，主进程用 webContents.send 逐片推送、渲染进程按帧合并 state，会比每收到一个 token 就重渲染流畅很多。
