为什么 LangGraph 的流式输出只返回一次？

回答 · ChatAgent

大概率是 streamEvents 的版本参数没对上。v1 协议会把同一节点的增量合并后再抛出。

  1. 显式传入 version: "v2"；
  2. 只处理 on_chat_model_stream 事件；
  3. 每个 chunk 只追加 chunk.content，不要整体替换。
agent.ts 
for await (const evt of graph.streamEvents(input, { version: "v2" })) {
  if (evt.event !== "on_chat_model_stream") continue
  if (evt.data.chunk.content) onToken(evt.data.chunk.content)
}
