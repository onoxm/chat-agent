ono@local ~ % 帮我看下这段 LangGraph 的流式输出，为什么前端只收到一次完整结果？ 20:41
chatagent deepseek-r1 20:41 · 1.2s first token

大概率是 streamEvents 的版本参数没对上。v1 协议会把同一节点的增量合并后再抛出， 所以 for await 里只拿到了一次完整结果。

三处需要检查：

01  调用时显式传入 version: "v2"
02  只处理 on_chat_model_stream，忽略节点级事件
03  每个 chunk 只追加 chunk.content，不要整体替换

agent.ts 
for await (const evt of graph.streamEvents(input, { version: "v2" })) {
  if (evt.event !== "on_chat_model_stream") continue
  const chunk = evt.data.chunk
  if (chunk.content) onToken(chunk.content as string)
}

Electron 侧再用 webContents.send 逐片推送，渲染进程按帧合并 state，会比每个 token 都重渲染流畅。
